## Data

| filename | sender | location |
| --- | --- | --- |
| registration_ic2s2.csv | Event registration | email |
| *.json | --- | ic2s2 main conference data |

`registration_ic2s2.csv` in this repo contains **synthetic example emails only**
(the real attendee list is private and lives outside the repo). To seed a real
deployment, drop the real CSV in this directory locally before running the seed
script — same shape: one email per row, first column, header row included.
